POSTallPost

POSTallPost is a Windows app for editing short videos and exporting MP4 files.

Edit a video

  1. Choose a video from your computer.
  2. Set the frame format, playback speed, and background blur.
  3. Choose whether to add automatic subtitles or import an SRT file.
  4. Export the finished video as an MP4 file.
